# Nexo Work Center

Target operational collaboration module for:

- workspace members
- roles and permissions
- tasks
- schedules
- staffing/time records
- operational tools
- alerts/communications

The former `the86club-workspace` contains useful prototypes for roles, profiles, team tasks, strategic task banks and task routing. Its latest source is preserved under `legacy/imports/the86club-workspace/v4.9.14.2/` for extraction, not used as the final architecture.
