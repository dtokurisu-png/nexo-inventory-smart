# Nexo Group applications

Permanent product modules belong here.

- `portal/` — Mi espacio, account, plans and workspace entry.
- `learning-core/` — personal learning product.
- `operations/` — Inventory Smart, Dynamic Technical Sheets, Dynamic Menus, Work Center.
- `camino-editorial/` — editorial platform.
- `commerce/` — The 86 Club and future commerce brands.
- `checkpoint/` — Nexo game distribution/catalog platform.

Active legacy paths are not moved blindly. They are migrated module by module and kept compatible until verified.
